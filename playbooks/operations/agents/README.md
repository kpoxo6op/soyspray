# Private evidence intake

`intake.yml` runs the reviewed fixed data transfer into the new agent-workshop
claim. It never creates or patches a workload. Push the clean source first.
Use the app README for promotion, archive identity, safeguards and recovery.
The operation writes only a private evidence report; tokens stay in memory.

The restore-test uses the same receiver and retained storage class with its own
claim identity. Both claims remain protected until a separate scoped retirement
operation is reviewed. Never use this operation against another namespace or
an existing application volume.
