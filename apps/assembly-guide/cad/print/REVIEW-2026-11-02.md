## Admission contract

The preparer requires clean, committed source, renderer, checker, dependency
locks and profiles. It renders into a new isolated directory and slices that
fresh STL; a stale or damaged cached repository STL never enters the job.
It rechecks input hashes and commit after preparation. Any process failure,
slicer warning, unsupported slice or input change leaves a failed report and
removes every exported job from that run. Existing run directories cannot be
reused or overwritten.

The independent geometry check reconstructs the placed CAD section at every
actual deposition layer. It rejects paths outside the mapped model, floating
starts, one-ended cantilevers, closed unsupported loops and bridges over 8 mm.
A bridge must span a gap and be anchored at both ends. It also checks the real
P1S bed exclusion and build height. Unknown transformations or G-code fail
closed. The supported scope is planar Bambu Studio 02.08.02.61 G-code, one P1S
0.4 mm object per plate. Structural CAD sections include designed infill
regions; the checker does not simulate each infill bead or physical material
behavior. The 8 mm limit is conservative admission policy, not a measured
universal PETG capability.

The MCP integration makes this a mandatory start boundary:

1. The server invokes its fixed configured preparer with `prepare_print_job`.
2. It validates the report and archive bytes, then creates an in-memory receipt.
3. Upload requires that receipt and an unchanged private snapshot.
4. Start downloads the remote bytes and verifies them against the receipt.
5. The last MQTT publish boundary requires a one-use start ticket. Direct
   start payloads and file-start G-code cannot bypass admission.

A restart forgets receipts and requires preparation/upload again. A missing
preparer disables printing. A caller-provided PASS report cannot grant access.
This contract must be verified on the deployed server separately; checking out
the CAD repository does not activate MCP enforcement.

## Reproducing the evidence

Install renderer dependencies in `cad/` with `npm ci`; install `uv` and the
qualified Bambu Studio Flatpak. `uv run --locked --script check-support.py`
uses the committed Python dependency lock. The public profiles contain no
printer connection credentials: 240°C nozzle, 75°C textured PEI, 0.2 mm layers,
four walls, five top/bottom layers, 15% gyroid, maximum 8 mm³/s.

```sh
node preflight.mjs ~/prints/new-job drive_tray switch_shelf
python3 check-preflight.py ~/prints/new-e2e-run
```

The E2E suite uses the real renderer and slicer. Historical source fixtures
reproduce unsupported rims, a floating model half, the excluded corner and a
warning-free long bridge. Positive cases prove that current shelves pass and
obsolete cached exports are ignored. Other cases cover process failure,
archive/G-code hash agreement, uncommitted inputs and preserving prior output.
These contracts were not owned by the app's geometry/layout tests. The nominal
256 mm bounding-box test was removed because it passed the excluded-corner
failure. No mock slicer or new unit tests are used. Output directories retain
reports, logs, G-code and rejection evidence; no E2E case contacts the printer.
